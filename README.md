# kpohw2
____________________________________


Это простое консольное приложение для учёта финансов.
В нем можно:

1. Создавать счета с балансом

2. Добавлять категории (доход / расход)

3. Добавлять операции

4. Смотреть баланс и аналитику

5. Импортировать операции из JSON

6. Экспортировать данные в JSON или CSV

____________________________________


S — Single Responsibility:
Каждый класс выполняет одну задачу: DomainFactory создаёт объекты, RepoProxy управляет данными, FinanceAnalyticsFacade считает аналитику

O — Open/Closed:
Можно добавить новый формат импорта/экспорта, не трогая существующий код

L — Liskov Substitution:
Все наследники (например, JSONImport и CSVImport) взаимозаменяемы

I - Interface Segregation:
Интерфейсы простые и небольшие

D - Dependency Inversion:
FinanceAnalyticsFacade, фасады и главный UI получают репозиторий и фабрику через DIContainer

GRASP (High Cohesion / Low Coupling):
Классы связаны минимально, каждый делает своё - структура читаемая и легко поддерживаемая

____________________________________


Использованные паттерны GoF:

1. Factory (Фабрика):
Используется в DomainFactory.
Отвечает за создание объектов (Account, Category, Operation) с проверкой данных
Удобнее контролировать логику создания

2. Facade (Фасад):
Это AccountFacade, CategoryFacade, OperationFacade, FinanceAnalyticsFacade
Каждый фасад объединяет действия, чтобы UI не обращался напрямую к внутренним классам
Код становится чище и проще в использовании

3. Command (Команда):
Используется в AddAccountCommand
Каждое действие оформляется как отдельная команда - удобно для расширения, логирования, измерения времени и т.д.

4. Decorator (Декоратор):
Класс TimeMeasureDecorator оборачивает команду и измеряет время её выполнения

5. Template Method (Шаблонный метод):
Используется в ImportTemplate + наследниках JSONImport и CSVImport
Есть общий алгоритм импорта, детали реализуются в конкретных классах - удобно при добавлении новых форматов

6. Visitor (Посетитель):
Используется в ExportVisitor, JSONExportVisitor, CSVExportVisitor
Позволяет легко добавлять новые форматы экспорта без изменения остального кода

7. Proxy (Прокси):
Класс RepoProxy оборачивает репозиторий и кэширует результаты
Это помогает ускорить доступ и изолировать логику хранения данных

____________________________________


Инструкция по запуску:

1. Откройте проект через PyCharm
2. Запуск:
	а) Запустите файл kpo2.py(если хотите самостоятельно потыкаться)
		а1) Следуйте указаниям в терминале, там всё понятно реализовано
	б) Запустите файл tests.py(добавил от себя юнит-тесты, которые демонстрируют работоспособность программы)
